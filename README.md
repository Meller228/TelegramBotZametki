# 📝 Notes Bot (Умные заметки на SQLite)

Telegram-бот на Python для создания, редактирования и удаления личных заметок. Данные сохраняются в локальной базе данных, поэтому не пропадают при перезапуске бота.

## 🛠 Технологии
* **Python 3**
* **pyTelegramBotAPI** (для работы с Telegram)
* **SQLite3** (встроенная база данных Python)

## ⚙️ Функционал
* `/start` — инструкция по использованию.
* `/add [текст]` — сохранить новую заметку.
* `/list` — показать все заметки пользователя (с уникальными ID).
* `/edit [ID] [новый текст]` — отредактировать существующую заметку по её ID.
* `/delete [ID]` — удалить заметку по ID.

## 🚀 Как запустить локально
1. Установите библиотеку: `pip install pyTelegramBotAPI`
2. Вставьте свой токен от `@BotFather` в переменную `TOKEN` в файле `bot.py`.
3. Запустите скрипт: `python bot.py`

## 💡 Пример использования
* `/add Купить хлеб` -> Бот: `✅ Заметка сохранена!`
* `/list` -> Бот: `[1] Купить хлеб`
* `/edit 1 Купить молоко` -> Бот: `✏️ Обновлено`
* `/delete 1` -> Бот: `🗑 Удалено`
